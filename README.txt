PAVEMENT DESIGN WEB APP — SIMPLE SETUP

1. Install Python from https://www.python.org/downloads/ if it is not already installed.
   On Windows, tick "Add Python to PATH" during installation.

2. Put app.py and requirements.txt in the same folder.

3. Open Command Prompt / Terminal in that folder and run:
   pip install -r requirements.txt

4. Then run:
   streamlit run app.py

5. The app opens in your web browser. If it does not open automatically, the terminal will show a local address to open.

Choose IRC:37-2018 or AASHTO 1993, enter your values, and click Calculate pavement design.

Note: the IRC calculation retains a simplified strain approximation and is for preliminary educational use, not a certified design.
